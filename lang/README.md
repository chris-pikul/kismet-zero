Suggested Development Milestones

Phase 1 — Foundations
	•	Implement phoneme/ and phonology/ (already underway).
	•	Provide RNG-safe utilities for reproducibility.
	•	Allow creating distinct phonologies per culture.

Phase 2 — Expression Layer
	•	Add orthography/ to map sounds → writing.
	•	Introduce basic lexicon generation (morphology/word.go).

Phase 3 — Structure
	•	Add grammar models (grammar/).
	•	Generate simple phrases/names consistently across world-building.

Phase 4 — Evolution
	•	Implement diachronic change (evolution/).
	•	Model divergence, convergence, and cross-cultural influence.

Phase 5 — Integration
	•	Link languages to cultural entities.
	•	Expose a high-level API for name/phrase generation.
	•	Provide hooks for Kismet’s world history simulation to drive language change.
